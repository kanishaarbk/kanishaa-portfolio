# Kanishaa Baraneetharan — Portfolio

A responsive static portfolio using HTML and CSS, with a small vanilla JavaScript mobile navigation toggle.

## Run locally
Open `index.html` in a browser, or serve this folder with VS Code Live Server.

## Deploy on Vercel
Import the repository/folder as a static project. No build command is required; the output directory is the project root.
